# Portfolio Rules

These rules apply to every page, component, animation, and feature.

Breaking these rules requires a strong justification.

---

# Identity

Always remember:

I am a fresher.

Do NOT make me appear as someone with years of professional experience.

Instead, showcase:

• curiosity

• engineering mindset

• practical projects

• continuous learning

• clean software development

Potential is more important than experience.

---

# Content Rules

Never invent experience.

Never invent internships.

Never invent achievements.

Never invent certifications.

Never invent metrics.

Never exaggerate project impact.

Everything must be truthful.

---

# Project Rules

Projects are the strongest part of this portfolio.

Every project must explain:

Problem

Solution

Architecture

Tech Stack

Challenges

Engineering Decisions

Future Improvements

Lessons Learned

Projects should feel like engineering case studies.

---

# Design Rules

Do NOT create:

Generic AI portfolios

Template-looking layouts

Skill percentage bars

Typing animations

Overly animated backgrounds

Huge gradients

Glassmorphism everywhere

Neon color schemes

Random floating shapes

Decorative clutter

Avoid unnecessary visual effects.

Every element must have a purpose.

---

# UI Rules

Prioritize:

Typography

Spacing

Hierarchy

Readability

Accessibility

Consistency

Responsive layouts

Minimalism

Use whitespace effectively.

---

# Code Rules

Use TypeScript.

Write reusable components.

Keep components focused.

Avoid large files.

Use meaningful names.

Keep folder structure clean.

Avoid duplicated code.

Follow Next.js best practices.

---

# Performance Rules

Optimize images.

Lazy load where appropriate.

Use Next.js Image.

Minimize bundle size.

Avoid unnecessary JavaScript.

Keep animations lightweight.

---

# Accessibility Rules

Semantic HTML.

Keyboard navigation.

Proper heading hierarchy.

ARIA labels where needed.

Accessible color contrast.

Responsive across all screen sizes.

---

# Portfolio Personality

Professional.

Thoughtful.

Confident.

Honest.

Engineering focused.

Minimal.

Never arrogant.

Never flashy.

---

# AI Behaviour

Before implementing anything ask:

Does this improve the portfolio?

Does this help recruiters understand my strengths?

Does this represent me honestly?

Would this make my portfolio stand out because of quality instead of visual gimmicks?

If the answer is no,

stop,

rethink,

and propose a better solution.

---

# Final Rule

Every decision should support one objective:

Build a portfolio that makes recruiters believe I am a fresher with exceptional potential and strong engineering fundamentals—not because of exaggerated claims, but because of the quality of my work, technical thinking, and attention to detail.
